管理员首次初始化

仅在第一次创建管理员时使用。管理员必须在 Cloudflare Worker Secret 中预先设置 ADMIN_BOOTSTRAP_SECRET。

成员注册

由管理员生成一次性邀请。成员在自己的 Raspberry Pi 上打开本页，绑定自己的 FIDO2 安全密钥；注册后等待管理员批准。

登录

登录前需要管理员批准成员和 Raspberry Pi 设备。注册完成后，ID 会保存在当前浏览器。

管理员控制

安全说明：本机代理使用 Ed25519 软件密钥证明持有设备密钥，不是 Raspberry Pi 芯片级证明。密钥文件位于 ~/.black-private/device-ed25519.pem。请勿复制或公开该文件。
